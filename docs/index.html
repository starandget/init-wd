💡 首次打开提示“已损坏”或“无法验证开发者”？

由于开源版本暂未购买付费 Apple Developer 签名证书，如遇 macOS Gatekeeper 拦截，将 Star Box 拖入「应用程序」后，在「终端（Terminal）」执行下面这一行命令解除隔离属性即可正常打开：

xattr -cr "/Applications/Star Box.app"

常见问题

关于局域网加速、Dock 备份还原与日常使用的常见疑问

启用「局域网加速」后，会影响我 Mac 上浏览器或其他软件的网络吗？ ＋

不会。Star Box 的加速通道是应用内隔离的——它只作用于 Star Box 自身发起的 Homebrew 子进程和 GitHub 下载请求，不会修改 macOS 的全局系统网络设置。

局域网设备已开启加速服务，为什么点「自动发现局域网加速」没扫出来？ ＋

请确认两点：1) 加速设备和 Mac 连接在同一个 Wi-Fi / 局域网下（且路由器未开启 AP 隔离）；2) 对应网络工具内已打开「允许局域网连接」（默认扫描常见端口：1082 / 7890 / 7897 / 6152 / 8888 / 8889 / 10809）。若使用了自定义端口，可在页面下方直接手动输入 IP:端口测试并启用。

「Dock 整理」点击一键应用后，如果不喜欢怎么恢复原来的 Dock？ ＋

每次点击「一键应用」前，Star Box 都会自动将你当前的 Dock 完整导出为 .plist 备份（最多保留最近 5 条）。在「Dock 整理」页面底部点击任意一条备份右侧的「恢复此备份」即可一秒还原。
